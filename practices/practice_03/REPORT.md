# Отчёт: локальные модели

## Окружение

- Windows 11 10.0.26200, 64-bit.
- Intel Core Ultra 9 285H, 16 ядер / 16 логических процессоров.
- Intel Arc 140T.
- RAM: 33683156992 байт.
- Ollama 0.35.1.

## Модель и конфигурация

Используется `qwen3.5:2b`: семейство `qwen35`, 2.3B параметров, формат GGUF, квантизация Q8_0, лицензия Apache-2.0. Базовая длина контекста модели — 262144 токена.

- [lab/Modelfile](lab/Modelfile): база `qwen3.5:2b`, `num_ctx 2048`, `temperature 0.2`.
- [lab/Modelfile.agent](lab/Modelfile.agent): база `qwen3.5:2b`, профиль `itmo-agent`, `num_ctx 65536`, `temperature 0.2`.

Компактная 2B-модель выбрана для локального запуска с ограниченным расходом памяти. Контекст агента задан отдельно от обычного профиля.

## Настройка OpenCode

В [lab/demo/opencode.json](lab/demo/opencode.json) выбрана модель `ollama/itmo-agent` и локальный Ollama endpoint `http://localhost:11434/v1`. Контекст — 65536 токенов, лимит ответа — 4096.

Агент `local-guide` работает только на чтение: разрешены `read`, `glob`, `grep`; остальные инструменты запрещены правилом `* deny`.

Для проверки подготовлены пять вопросов из [QUESTIONS.md](lab/QUESTIONS.md). Ответы сохранены в `lab/results/q1.jsonl` … `q5.jsonl` и сопоставлены с кодом demo. Полные ответы и подтверждения по коду приведены в [lab/answers.md](lab/answers.md).

## Вывод

Локальная модель подключена к OpenCode через Ollama, агент ограничен чтением файлов. Модель справилась не со всеми вопросами. Основные проблемы проявились при поиске источника информации и попытках дополнить ответ неподтверждёнными предположениями.
