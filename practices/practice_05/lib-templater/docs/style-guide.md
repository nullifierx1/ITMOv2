# Style Guide (Practice 4)

Короткие правила для демо-проекта lib-templater:

1) CMake layout и зависимости
- Использовать текущую структуру CMake.
- Новые зависимости добавлять только при реальной
  необходимости.

2) Проверки изменений
- Проверять через GoogleTest + CTest и
  sh scripts/check.sh.

3) Форматирование и стиль
- Соблюдать .clang-format и .editorconfig.
- Не вводить конфликтующий стиль.

4) Минимальный diff
- Для маленьких задач делать минимальные правки.
- Не исправлять unrelated проблемы и не делать
  refactor без причины.

Пример
- Хорошо: исправить ссылку на test source и добавить
  один минимальный smoke test.
- Плохо: одновременно переписывать CMake, менять CI,
  менять C++ standard и реорганизовывать весь template.
