# Unit-проверки

Файл ведёт OpenCode. Обсудите с агентом содержание и проверьте предложенный
diff. Все дополнения и исправления поручайте агенту в чате.

| Требование или правило | Что проверяем изолированно | Вход | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| Добавление трека | `Library::addTrack` и размер библиотеки | Новый тестовый трек | Добавление успешно, размер увеличен на 1 | TO BE ADR, use case add |
| Поиск известного трека | `Library::getTrack` | Ранее добавленный трек и его имя | Возвращён ожидаемый `shared_ptr<Track>` | TO BE ADR, use case get |
| Удаление трека | Операция remove | Ранее добавленный трек | Размер уменьшен, дальнейший поиск возвращает пустой `shared_ptr` | TO BE ADR, use case remove |
| Согласованность индекса | Данные и индекс после add и remove | Несколько тестовых треков, затем удаление одного | Индекс содержит позиции доступных треков и не содержит удалённый | TO BE ADR, `Library` AS IS содержит индекс |
| Слабая ссылка плейлиста | `Playlist::addTrack` | Непустой `shared_ptr<Track>` | Добавлена не-владеющая `weak_ptr` | TO BE ADR, use case playlist |
| Инкапсуляция | Публичная поверхность `Library` и `Playlist` | Компиляционный контракт | Нет публичного API, возвращающего mutable-ссылку на контейнер | TO BE ADR |

## Как использовали AI

- Для чего: составить unit-проверки целевых инвариантов.
- Тип промпта: структурированный промпт с ограниченным контекстом.
- Строка в [`prompts.md`](prompts.md): P1-03.
- Что проверил студент и какие исправления поручил агенту: ожидаемые результаты взяты из принятого
  TO BE-контракта, а не из отсутствующей реализации.
