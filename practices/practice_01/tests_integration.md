# Integration-проверки

Файл ведёт OpenCode. Обсудите с агентом содержание и проверьте предложенный
diff. Все дополнения и исправления поручайте агенту в чате.

| Связь компонентов | Что может сломаться | Как воспроизводим | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| `Library` и `LibraryManager` | Фасад может обойти доменную операцию | Добавить, получить и удалить трек через manager | Результаты совпадают с контрактом `Library`, индекс согласован | TO BE ADR |
| `Library` и `Playlist` | Плейлист может продлить жизнь удалённого трека | Добавить трек, добавить его в плейлист, удалить из библиотеки | Ссылка в плейлисте становится `expired()`, плейлист не владеет треком | TO BE ADR, `weak_ptr` в `playlist.h` |
| Последовательность add → get → remove | Шаги могут рассогласовать библиотеку и индекс | Добавить трек, найти, удалить, найти повторно | Найденный трек доступен до удаления, затем поиск пустой | TO BE use cases |
| Несколько операций с индексом | Индекс может содержать удалённую запись | Добавить несколько треков, удалить один, искать остальные | Остальные треки доступны, индекс согласован | TO BE ADR |

- Строка в [`prompts.md`](prompts.md): P1-03.
